# Notebooks

Survival prediction (Cox proportional hazards, event = death, `OS.time` as
follow-up) on TCGA-BRCA from three omics modalities: RNA-seq and DNA
methylation as high-dimensional (HD) modalities, a 5-feature CNV subset as
the low-dimensional (LD) modality. Compares the OrchAMP method (this
project) in three fusion configurations against MOFA+ and Multigrate.

## OrchAMP (this project's method)

| Notebook | Fusion strategy |
|---|---|
| `orchamp_brca_survival_early_fusion.ipynb` | All modalities pooled into one cluster before AMP denoising |
| `orchamp_brca_survival_intermediate_fusion.ipynb` | Cluster count auto-selected via the Gap statistic (k=1 allowed) |
| `orchamp_brca_survival_late_fusion.ipynb` | One cluster per modality (EB-PCA), each denoised independently |

These three import `Python_scripts/` (`sys.path.append("../Python_scripts")`)
— see `../Python_scripts/README.md` for the pipeline module chain.

## Baselines (train → test, per method)

| Train | Test | Method |
|---|---|---|
| `train_mofa_brca_survival.R` | `test_mofa_brca_survival.ipynb` | [MOFA2 (Argelaguet et al., 2018)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6010767/) + Cox (train in R, test in Python) |
| `train_multigrate_brca_survival.ipynb` | `test_multigrate_brca_survival.ipynb` | [Multigrate](https://github.com/theislab/multigrate) + Cox |

No JAFAR or Cooperative Lasso baseline for this dataset.

Each `train_*` fits a MOFA/Multigrate embedding plus a downstream linear Cox
head on the frozen training split, saving the model + embedding
scaler/Cox coefficients; each matching `test_*` loads that and evaluates on
the frozen test split (train/test split concordance-index, where available).

## Aggregation

`create_summary_brca_survival.ipynb` — runs last. Collects the saved
train/test C-index (concordance index) from all of the above into one
summary table for `brca_survival`.

## Directory expectations

Every notebook/script here reads/writes relative to this folder's parent,
i.e. it expects to sit at `TCGA-BRCA Data Analysis/Notebooks/`:

```
TCGA-BRCA Data Analysis/
├── Pre-processing/
├── Notebooks/           <- this folder
├── Python_scripts/      <- used by the orchamp_brca_survival_* notebooks only
├── data/                 <- raw Xena downloads, incl. BRCA_survival.tsv (see Pre-processing/README.md)
├── matrices/              <- from Pre-processing/ (per-modality U/D/V/X/Z + CNV_X_ld_features.csv)
├── splits/                <- from Pre-processing/generate_brca_survival_splits.ipynb
├── models/                <- where train_* scripts save models; where test_* scripts load them from (not included in this push)
└── results/               <- where train_*/test_* scripts save metrics/predictions; where create_summary reads from (not included in this push)
```

`data/`, `matrices/`, and `splits/` are generated by the notebooks in
`../Pre-processing/` — see that folder's README for the full run order.
`models/` and `results/` are produced by the notebooks in this folder and
aren't pushed here (trained model artifacts and result files, not code).
